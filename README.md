## 🚀 Hướng Dẫn Sử Dụng

### 1. Setup Local Development
```bash
# Clone hoặc download project
cd landing-page-yola

# Mở bằng Live Server (VS Code extension)
# Hoặc dùng Python SimpleHTTPServer
python -m http.server 8000

# Hoặc Node.js http-server
npx http-server -p 8000
```

### 2. Chỉnh Sửa Nội Dung
**HTML** (`index.html`):
- Tìm section cần chỉnh sửa (dùng comment `<!-- Section Name -->`)
- Update text, links, images

**CSS** (`css/style.css`):
- Variables ở đầu file (colors, fonts, spacing)
- Tìm class name để chỉnh sửa styles
- Responsive rules ở cuối file

**JavaScript** (`js/main.js`):
- Event listeners đã setup sẵn
- Form handling tại `contactForm.addEventListener('submit'...)`
- Analytics tracking có thể customize

### 3. Tích Hợp Google Analytics 4
Thêm vào `<head>` của `index.html`:
```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

### 4. Tích Hợp Form Backend
Thay thế phần form submission trong `js/main.js`:
```javascript
// Line ~130: Replace setTimeout simulation with real API call
```

## 📈 KPI & Conversion Tracking

### Primary Conversion Goals
1. **Form Submit** - Contact form điền đầy đủ và gửi
2. **Phone Click** - Click hotline button/link
3. **CTA Click** - Click "Nhận tư vấn" hoặc "Chọn gói"
4. **Scroll Depth** - Đọc qua ≥50% trang

### Secondary Metrics
- Time on page (avg >3 minutes)
- Bounce rate (<40%)
- Pages per session (1.2+)
- Section visibility (FAQ, Pricing, Case Study)

### GA4 Events Setup
Tất cả events đã được code sẵn trong `js/main.js`:
- `form_submit` (event_category: 'engagement')
- `click_hotline` (event_category: 'engagement')
- `click` (event_category: 'CTA')
- `section_view` (event_category: 'engagement')
- `timing_complete` (event_category: 'Page Performance')
